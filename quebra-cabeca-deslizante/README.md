# Quebra-Cabeça Deslizante

Jogo em React + TypeScript + Vite inspirado na estrutura visual do vídeo enviado.

## Recursos
- Quebra-cabeça deslizante 3x3, 4x4 e 5x5
- Imagem da paisagem extraída do vídeo como base
- Cronômetro
- Contador de movimentos
- Barra de progresso
- Tela de vitória
- Layout responsivo para celular e PC

## Rodar no VS Code
```bash
npm install
npm run dev
```

Abra o endereço mostrado pelo Vite no navegador.

A imagem usada está em `public/images/paisagem.jpg`. Para colocar exatamente suas imagens originais, substitua esse arquivo mantendo o mesmo nome.
